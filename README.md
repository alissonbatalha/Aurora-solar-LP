# Aurora Solar

Landing page responsiva para a Aurora Solar, criada para apresentar soluções de energia solar e incentivar o contato com a equipe.

## Sobre o projeto

A página reúne informações sobre vantagens da energia solar, depoimentos ilustrativos, etapas de contratação e um simulador simples de economia. O layout se adapta a celulares, tablets e computadores.

## Recursos

- Menu de navegação responsivo, com menu expansível em telas menores.
- Seções de apresentação, vantagens, depoimentos e etapas do serviço.
- Simulador que estima uma economia de até 90% com base no valor mensal da conta informado.
- Botões de contato por e-mail.
- Preferência por movimento reduzido respeitada no CSS.

## Como visualizar

O projeto é estático e não precisa de instalação de dependências ou etapa de build. Abra `index.html` diretamente no navegador ou inicie um servidor local na pasta do projeto, por exemplo:

```bash
python -m http.server 8000
```

Depois, acesse <http://localhost:8000>.

## Observação sobre o simulador

O resultado exibido é apenas uma estimativa demonstrativa, calculada como 90% do valor informado. Não representa uma proposta comercial nem considera tarifas, localização, consumo detalhado ou características do imóvel.
